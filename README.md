# 呈界 · AI 创作工作台

Windows 客户端安装包与公开发行说明。包含画布、AI Dex 智聊与自动影片工作室。

从本仓库的 [Releases](https://github.com/davieron/lipanpan/releases) 下载安装包。下载后可按同版本的 `SHA256SUMS.txt` 核对文件完整性。

## 安装与资料

运行安装向导并按提示选择安装位置。更新前建议备份重要资料，保留原画布、素材和工作记录。不要为更新手动删除整个资料目录；旧智聊数据与新版数据方式的兼容处理以客户端提示和版本说明为准。

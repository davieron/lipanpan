# 呈界 · AI 创作工作台

Windows 客户端安装包与公开发行说明。包含画布、AI Dex 智聊与自动影片工作室。

从 [Releases](https://github.com/davieron/lipanpan/releases) 下载已正式发布的版本，并按同版本 `SHA256SUMS.txt` 核对安装包。本次发行版本为 2.2.15。

## 安装与资料

按安装向导提示选择安装位置。更新前建议备份重要资料，不要手动删除整个账号、项目或素材目录。画布、素材和聊天数据按当前版本的升级方式保留；发现问题时请先记录版本号与复现步骤。
